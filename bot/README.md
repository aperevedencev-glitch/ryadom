# Телеграм-бот «Рядом»

Устроен так же, как бот Salon de Fleur «Цветочная гостиная»: один бот на Cloudflare Workers в двух ролях. Свой сервер не нужен, бесплатного тарифа Cloudflare хватает с запасом.

1. **Консультант.** Клиент пишет боту `/start` и получает меню:
   - **Психологи** — анкета каждого с фото, темами, подходом, ценой и ближайшими свободными окнами;
   - **Подобрать по теме** — 16 тем, по каждой бот показывает подходящих специалистов;
   - **Записаться** — выбрать психолога (или «Помогите подобрать») и ответить на сообщение бота именем, контактом и удобным временем. Заявка сохраняется в ту же таблицу Supabase `bookings`, что и с сайта, и приходит координатору;
   - **Цены и формат**, **Первая встреча**, **Конфиденциальность**, **ИИ-собеседник**;
   - **Написать координатору** — любое сообщение клиента (текст, фото, голосовое) бот пересылает координатору. Координатор нажимает **Ответить (Reply)**, и бот отправляет ответ клиенту;
   - **Срочная помощь** — телефоны 112, детского телефона доверия и МЧС.

   Если в сообщении клиента есть слова о желании умереть или навредить себе, бот сразу присылает ему телефоны экстренной помощи, а координатору сообщение приходит с пометкой 🚨.
2. **Уведомления.** Формы сайта (запись, заявка психолога, подписка) сохраняют данные в Supabase и отправляют копию на адрес `/lead`. Бот присылает её координатору в личные сообщения.

## Как запустить (≈15 минут)

### 1. Создать бота в Телеграме
1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Имя — «Рядом — психологи онлайн», адрес должен заканчиваться на `bot`, например `ryadom_psy_bot`.
3. BotFather пришлёт **токен** вида `1234567890:AA...`. Никому его не показывайте.

### 2. Создать Worker в Cloudflare
1. [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages → Create → Create Worker**.
2. Назовите его `ryadom-bot` и нажмите **Deploy**.
3. **Edit code** → удалите всё и вставьте содержимое файла `worker.js` (не `worker.src.js`). Нажмите **Deploy**.
4. Запишите адрес воркера, например `https://ryadom-bot.ваше-имя.workers.dev`.

### 3. Задать переменные
**Settings → Variables and Secrets**:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен от BotFather |
| `WEBHOOK_SECRET` | Secret | любая строка из латиницы и цифр, 20+ символов, например `Ryadom2026SecretKey77` |
| `SITE_URL` | Text | адрес сайта, например `https://ryadom.vercel.app/` |
| `ALLOWED_ORIGIN` | Text | тот же адрес без пути: `https://ryadom.vercel.app` (несколько — через запятую) |
| `ADMIN_CHAT_ID` | Text | пока пусто, заполните на шаге 5 |

`SUPABASE_URL` и `SUPABASE_KEY` задавать не нужно: по умолчанию бот пишет записи в тот же проект Supabase, что и сайт.

### 4. Подключить бота
Откройте в браузере:
```
https://ryadom-bot.ваше-имя.workers.dev/setup?key=ВАШ_WEBHOOK_SECRET
```
Должен появиться ответ с `"ok":true`: вебхук подключён, меню команд и описание бота установлены.

### 5. Узнать chat id координатора
1. С аккаунта координатора напишите боту `/id`.
2. Вставьте число в `ADMIN_CHAT_ID` и нажмите **Deploy**.

Напишите боту `/start` — придёт подсказка для координатора. `/client` показывает меню глазами клиента.

### 6. Подключить сайт
В начале `common.js` заполните две строки:
```js
const LEAD_URL = "https://ryadom-bot.ваше-имя.workers.dev/lead";
const BOT_USERNAME = "ryadom_psy_bot";   // без @
```
После этого заявки с сайта начнут приходить в Телеграм, в подвале появится ссылка «Написать в Telegram», а в анкете психолога — кнопка «Записаться в Telegram». Она открывает в боте анкету этого специалиста.

## Проверка
- `https://адрес-воркера/status` — задан ли токен, куда смотрит вебхук (`webhook_points_here: true`), последняя ошибка доставки, заданы ли `ADMIN_CHAT_ID` и `WEBHOOK_SECRET`.
- `https://адрес-воркера/test-lead?key=ВАШ_WEBHOOK_SECRET` — координатору придёт тестовая заявка.

## Как поменять данные
- **Психологи.** Бот берёт их с сайта. После правок в `psychologists-data.js` выполните `node bot/sync-data.mjs`: команда пересоберёт `worker.js`, вставьте его в Cloudflare заново.
- **Тексты меню.** Функция `section()` в `worker.src.js`, затем снова `node bot/sync-data.mjs`.
- **Слова-признаки кризиса.** Выражение `CRISIS_RE` в `worker.src.js`.

## Защита
- Телеграм присылает вебхук с секретным заголовком, чужие запросы на `/webhook` отклоняются.
- `/lead` принимает заявки только с адреса из `ALLOWED_ORIGIN` и требует контакт (или email для подписки).
- Скрытое поле-ловушка `website` отсекает спам-ботов.
- Ключ Supabase в боте публичный и даёт только право добавить запись: прочитать заявки через него нельзя.
